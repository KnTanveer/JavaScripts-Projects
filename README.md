This repository contains a collection of mini JavaScript projects built as part of my learning journey. The goal of this repo is to strengthen core JavaScript concepts through hands-on practice and small interactive applications.

To keep the focus on JavaScript development, all projects share a single global stylesheet. This reduces repetitive UI work and allows more time to experiment with functionality, logic, and problem-solving.

## What You'll Find

* CRUD operations
* DOM manipulation 
* Interactive UI components
* Reusable styling across projects

## Purpose

This repository serves as:

* A personal learning archive
* A playground for experimenting with JavaScript concepts
* A way to track progress over time
